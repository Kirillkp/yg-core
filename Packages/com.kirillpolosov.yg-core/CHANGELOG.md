# Журнал изменений

Формат основан на Keep a Changelog, версии по SemVer. Подробности по каждой версии, включая инструкции по переносу для игр, лежат в `Documentation~/versions/vX.Y.Z.md`.

Разделы записи: **Добавлено**, **Изменено**, **Исправлено**, **Удалено**, **Ломающие изменения** (последний раздел всегда ссылается на инструкцию по переносу).

## [Unreleased]

Сюда агенты и разработчики добавляют строки по мере работы. Перед выпуском раздел превращается в запись версии.

### Исправлено
- Две операции подряд (например, две записи сохранения) могли зависнуть в WebGL: сервисы сохранения, покупок и `ProgressionService` ставили операции в очередь через `SemaphoreSlim`, а в WebGL нет пула потоков, на котором возобновляется ожидание занятого семафора. Заменено на `AsyncGate` (новый класс в `YgCore.Core`, очередь без потоков).
- Мосты к PluginYG2 не попадали в сборку игры: скрипты пакета без `.asmdef` Unity в `Assembly-CSharp` не берёт. Теперь исходники мостов лежат в `Runtime/YandexBridge~`, а установщик `YgCore.Editor.YandexBridgeInstaller` копирует их в `Assets/YgCore/YandexBridge` игры и обновляет при смене версии пакета (DEC-022).

- Документация аудио: в сцене обязателен `AudioListener`, иначе в сборке WebGL звука нет (в редакторе его не видно).

### Изменено относительно «Обби Потоп»
- Звук: при рекламе, паузе платформы, покупке и потере фокуса останавливается весь звук, а не только музыка; отсчёт «3-2-1» музыку не останавливает (исправление двух недосмотров «Обби»). Подробно: `modules/audio.md`.

### Добавлено
- Модуль **Core** (`YgCore.Core`): состояния приложения, координатор паузы, экономика с идемпотентными транзакциями, настройки звука, задержка в реальном времени. Перенесён из «Обби Потоп». Документ: `modules/core.md`.
- Модуль **Контракты платформы** (`YgCore.Contracts`): интерфейсы рекламы, авторизации, покупок, сохранения, лидерборда, локализации, готовности, жизненного цикла, аудиофокуса и аналитики. Перенесён из «Обби Потоп». Документ: `modules/contracts.md`.
- Модуль **Локализация** (`YgCore.Localization`): `ILocalizationCatalog` и `DictionaryLocalizationCatalog` (нормализация языка, запасной язык, подстановка аргументов). Тексты остаются в игре. Документ: `modules/localization.md`.
- Модуль **Моки редактора** (`YgCore.Mocks`): моки рекламы, аналитики, аудиофокуса, авторизации, готовности, жизненного цикла, таблицы лидеров, локализации, покупок и хранилища со сценариями исхода. Документ: `modules/mocks.md`.
- Модуль **Фабрики и заглушки** (`YgCore.Factories`), пока только заглушки «платформа недоступна». Фабрики придут вместе с Яндекс-модулем. Документ: `modules/factories.md`.
- Модуль **Яндекс-реализация** (`YgCore.Yandex` и мосты `YandexBridge~`, которые устанавливаются в проект игры): сервисы рекламы, авторизации, покупок, сохранения, лидерборда, локализации, готовности и жизненного цикла на PluginYG2; мосты и три `.jslib`; заплатки с подтверждением сохранения и покупок. Документ: `modules/yandex.md`.
- Модуль **Сохранения и прогресс** (`YgCore.Save`): `ProgressionService<TData>` (загрузка, защита непрочитанного прогресса от затирания, пакетная и немедленная запись, повтор после сбоя, лимит размера, слияние гостя с облаком, сброс), `ProgressionCodec<TData>`, `ProgressionData` (конверт), `IProgressionSchema<TData>` и `IProgressionBinding<TData>` для игры, помощники `ProgressionLists` и `SettingsProgressData`. Формат JSON совместим с «Обби Потоп». Документ: `modules/save.md`.
- Модуль **Магазин** (`YgCore.Store`): `SessionStoreService` (покупка за монеты, покупка за реальные деньги с выдачей в два шага «запись прогресса, затем подтверждение платформе», защита от двойной выдачи по токену, невыданные покупки при старте, экипировка со снятием аксессуаров, восстановление из сохранения), `StoreItemDefinition` с типами товара (`Equippable`, `CurrencyPack`, `Unlock`), типизированные результаты `StoreStatus` и ключи строк `StoreStatusKeys`, правила слотов `IStoreEquipmentRules` и `StoreSlotBlockingRules`, `EquippedItemProgressData` для прогресса. Формат сохранённого совместим с «Обби Потоп». Документ: `modules/store.md`.
- Модуль **Аудио** (`YgCore.Audio`, необязательная `YgCore.Audio.UI`): базовый `AudioDirector` (музыка, заставка, пул голосов для эффектов с ограничением частоты, зацикленные звуки, громкость из настроек с кривой, приглушение музыки по состоянию, остановка звука при жёсткой паузе), чистые правила `AudioPolicy` и `SfxThrottle`, `AudioSettingsApplier`, `UiPressSounds` (звук нажатия на uGUI при наличии uGUI и Input System). Игра наследует директор и подписывается на свои события. При жёсткой паузе (реклама, платформа, покупка, фокус) останавливается весь звук, а отсчёт `Countdown` звук не держит. Настройка `silenceEffectsOnHardPause` (по умолчанию включена) позволяет оставить эффекты звучать во время таких пауз. Документ: `modules/audio.md`.
- Модуль **Web-качество** (`YgCore.WebQuality`): при запуске WebGL-сборки выбирает уровень качества для компьютера или телефона и частоту кадров (настройки в `Resources/WebQualitySettings`, JavaScript определяет мобильное устройство), правила в чистых функциях `WebQualityPolicy`. Документ: `modules/web-quality.md`.
- **`LocalizedTextView`** (необязательная сборка `YgCore.Localization.UI`, подключается при наличии uGUI): подстановка строк в uGUI `Text` с обновлением при смене языка. Документ: `modules/localization.md`.
- **Фабрики** сервисов в `YgCore.Factories` (редактор: мок, WebGL с модулем PluginYG2: Яндекс, иначе заглушка).
- Описание доработок PluginYG2 (`Documentation~/patches`).
- Конструктор `SessionGameSettingsService(music, sfx)` для своих стартовых громкостей (без параметров значения прежние: 0.5 и 0.1).
- Файлы `.meta` для пакета (нужны Unity для пакетов из git), генератор `Tools/generate-meta.py`.
- Проверка Яндекс-модуля без Unity: `Tools/YandexChecks` (47 проверок с заглушкой PluginYG2), компиляция ветки WebGL, `Tools/check-jslib.py` (согласованность имён C# и JavaScript).
- Проверка логики без Unity: `Tools/CoreChecks` (224 проверки: Core, Save, Store, Audio, WebQuality, LocalizedTextView, каталог локализации, моки, заглушки) и `Tools/check-samples.py` (образец кода в документации совпадает с проверяемым).
