# Журнал изменений

Формат основан на Keep a Changelog, версии по SemVer. Подробности по каждой версии, включая инструкции по переносу для игр, лежат в `Documentation~/versions/vX.Y.Z.md`.

Разделы записи: **Добавлено**, **Изменено**, **Исправлено**, **Удалено**, **Ломающие изменения** (последний раздел всегда ссылается на инструкцию по переносу).

## [Unreleased]

Сюда агенты и разработчики добавляют строки по мере работы. Перед выпуском раздел превращается в запись версии.

### Добавлено
- Модуль **Core** (`YgCore.Core`): состояния приложения, координатор паузы, экономика с идемпотентными транзакциями, настройки звука, задержка в реальном времени. Перенесён из «Обби Потоп». Документ: `modules/core.md`.
- Модуль **Контракты платформы** (`YgCore.Contracts`): интерфейсы рекламы, авторизации, покупок, сохранения, лидерборда, локализации, готовности, жизненного цикла, аудиофокуса и аналитики. Перенесён из «Обби Потоп». Документ: `modules/contracts.md`.
- Конструктор `SessionGameSettingsService(music, sfx)` для своих стартовых громкостей (без параметров значения прежние: 0.5 и 0.1).
- Файлы `.meta` для пакета (нужны Unity для пакетов из git), генератор `Tools/generate-meta.py`.
- Проверка логики Core без Unity: `Tools/CoreChecks` (25 проверок).
