# YG Core

Общая механика для игр на Яндекс Играх (Unity WebGL).

## Для чего нужен

Любая игра для Яндекс Игр заново решает одни и те же задачи: пауза при рекламе, авторизация, покупки, облачное сохранение, лидерборд, язык. Пакет решает их один раз, проверяет на стенде в консоли Яндекса и версионирует, чтобы новые игры строились на проверенной основе.

## Что внутри

| Модуль | Сборка | Назначение |
|---|---|---|
| Core | `YgCore.Core` | Состояния приложения, пауза, экономика, настройки |
| Контракты платформы | `YgCore.Contracts` | Интерфейсы реклама/авторизация/покупки/сохранение/лидерборд/язык |
| Сохранения | `YgCore.Save` | Прогресс игрока: конверт и версия схемы, миграции, защита от потери, слияние гостя с облаком |
| Магазин | `YgCore.Store` | Покупки за монеты и за реальные деньги, экипировка, выдача в два шага (только логика, без экранов) |
| Аудио | `YgCore.Audio` (+ необязательная `YgCore.Audio.UI`) | Музыка и звуки, громкость из настроек, остановка при рекламе, звук нажатия на интерфейс |
| Локализация | `YgCore.Localization` (+ необязательная `YgCore.Localization.UI`) | Каталог строк игры, нормализация языка, подстановка строк в надписи uGUI |
| Web-качество | `YgCore.WebQuality` | Выбор уровня качества и частоты кадров для компьютера и телефона в браузере |
| Фабрики и заглушки | `YgCore.Factories` | Выбор реализации: Яндекс, мок или «недоступно» |
| Моки | `YgCore.Mocks` | Работа без консоли Яндекса |
| Яндекс-реализация | `YgCore.Yandex` | Адаптеры PluginYG2 и заплатки с подтверждением операций |

Состав уточняется по мере переноса кода из «Обби Потоп». Актуальный статус каждого модуля в [Documentation~/00-index.md](Documentation~/00-index.md).

Экранов (UI) в пакете нет: они живут в игре и в шаблонах.

## Быстрый старт

1. Подключите пакет по git-URL с закреплённой версией: [Documentation~/install.md](Documentation~/install.md).
2. Подключите PluginYG2 нужной версии (см. [compatibility.md](Documentation~/compatibility.md)).
3. Прочитайте [architecture.md](Documentation~/architecture.md): какие слои зависят друг от друга и чего делать нельзя.
4. Для нужной функции откройте модульный документ или рецепт из индекса.

## Проверка

Перед выпуском каждой версии пакет проверяется на тестовом стенде `Stand/` в консоли Яндекса. Чек-лист: `Docs/STAND_CHECKLIST.md` в корне репозитория.
