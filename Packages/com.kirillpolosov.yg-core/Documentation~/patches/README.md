# Доработки PluginYG2

Пакет работает с PluginYG2 v2.0092 (см. [compatibility.md](../compatibility.md)). Плагин сторонний и лежит в проекте игры, пакет его не меняет. Если для надёжной работы нужна правка файла плагина, она описана здесь.

| Доработка | Нужна пакету? | Что будет без неё |
|---|---|---|
| [Сообщение о закрытии окна входа](pluginyg2-auth-dialog-closed.md) | Рекомендуется | Отмена входа определяется только по таймауту 30 секунд и возвращается как `Error`, а не `Denied` |

## Правки плагина в «Обби Потоп», которые пакету не нужны

В «Обби Потоп» плагин изменён ещё в двух местах. Эти правки относятся к игре или к сборке, а не к пакету:

- `InterAdv_yg.cs`: таймер первой полноэкранной рекламы при старте игры. Это политика показа рекламы конкретной игры (решать при создании каждой игры).
- `ArchivingBuild.cs`: упаковка zip-архива без служебных файлов macOS (`.DS_Store`, `__MACOSX`, `._*`). Это инструмент сборки для публикации, он войдёт в отдельный набор редакторных инструментов (см. `Docs/MIGRATION_FROM_OBBY.md`).

## Как применять доработку при обновлении PluginYG2

Правки в файлах плагина пропадают при его обновлении. После обновления PluginYG2:

1. Проверьте, что файл по-прежнему подходит под описанный фрагмент.
2. Примените доработку снова.
3. Пройдите чек-лист стенда (секция «Авторизация»).
