# Архитектура

## Главная идея

Игра говорит с платформой через **контракты** (интерфейсы). Что стоит за контрактом, решают **фабрики**: Яндекс на платформе, мок в редакторе или безопасная заглушка «недоступно». Поэтому игре всё равно, где она запущена, а платформу можно заменить, не трогая игру.

## Слои и зависимости

Стрелка «A → B» значит «A использует B».

```
Игра ───────────────→ Save, Store, Audio, Localization, Core, Contracts
Сборка игры (старт) ─→ Factories, Core
Стенд ──────────────→ Factories, Save, Store, Audio, Localization, Core, WebQuality

Save, Store → Core, Contracts
Localization ───────→ (ни от чего не зависит)
Audio ──────────────→ Core
Factories ──────────→ Contracts, Localization, Mocks, Yandex
Mocks ──────────────→ Contracts, Localization
Yandex ─────────────→ Contracts, PluginYG2, JS-заплатки

Core, Contracts ────→ (ни от чего не зависят)
```

## Сборки (assembly definitions)

| Сборка | Назначение | Может ссылаться на |
|---|---|---|
| `YgCore.Core` | состояния, пауза, экономика, настройки | ничего |
| `YgCore.Contracts` | интерфейсы и типы результатов | ничего |
| `YgCore.Save` | схема, миграции, кодек сохранения | Core, Contracts |
| `YgCore.Store` | каталог и покупки | Core, Contracts |
| `YgCore.Audio` | музыка и звуки | Core |
| `YgCore.Localization` | каталог строк игры и нормализация языка | ничего |
| `YgCore.WebQuality` | настройки качества для браузера | ничего |
| `YgCore.Mocks` | фальшивая платформа | Contracts, Localization |
| `YgCore.Yandex` | PluginYG2 и заплатки | Contracts, Core |
| `YgCore.Factories` | выбор реализации, заглушки «недоступно» | Contracts, Localization, Mocks, Yandex |

Список согласован с планом переноса и уточняется вместе с кодом.

## Жёсткие правила

1. Игра и любые модули кроме `YgCore.Yandex` не обращаются к PluginYG2 и Яндекс SDK напрямую.
2. `YgCore.Core` и `YgCore.Contracts` не получают ссылок на другие сборки пакета.
3. Валюта меняется только транзакциями экономики. Интерфейс ничего не пишет в баланс или сохранение сам.
4. Пауза складывается из причин: `User`, `Platform`, `Ad`, `Purchase`, `Focus`. Игра возобновляется, только когда сняты все причины.
5. Операции с платформой, которые что-то меняют (сохранение, покупка), подтверждаются явно. Сбой нельзя превращать в «пустое» состояние: сбойная загрузка не должна стать пустым сохранением, покупка не считается выданной до подтверждения игры.
6. Параметры (скорости, цены, товары, строки) хранятся в данных, а не в коде.
7. UI в пакете нет. Экраны живут в игре и в шаблонах и берут логику из пакета.

## Почему так

- **Контракты** позволяют проверять игру без Яндекса (моки) и не падать, когда платформы нет (заглушки).
- **Заплатки PluginYG2** нужны, потому что штатные сохранение и покупки не дают надёжного подтверждения. Подробнее в modules/yandex.md (после переноса) и `Docs/DECISIONS.md`.
- **Один пакет вместо нескольких**: проще версионировать. Деление на сборки позволит вынести части позже без переделки.
