# Совместимость

Таблицы обновляются в том же изменении, в котором меняется совместимость. Версия пакета выпускается только после проверки на стенде в указанном окружении.

## Версии пакета и окружение

| Версия пакета | Unity | PluginYG2 | Модули PluginYG2 | Схема сохранения | Статус |
|---|---|---|---|---|---|
| 0.0.0 | не определено | не определено | не определены | нет | скелет, кода нет |

Для ориентира, на чём работает «Обби Потоп» сейчас (из которого переносится код): Unity 6000.6.0f1, PluginYG2 v2.0092 (Storage v1.021, Payments v1.02), URP 17.6.0, Input System 1.20.0, uGUI 2.6.0.

## Схема сохранения

Каждое сохранение содержит номер схемы. При любом изменении формата номер поднимается, и добавляется миграция со старой схемы.
