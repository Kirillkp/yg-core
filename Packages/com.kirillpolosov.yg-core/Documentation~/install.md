# Подключение и обновление

## Требования

Актуальные версии смотрите в [compatibility.md](compatibility.md). Коротко: Unity 6, PluginYG2 строго указанной версии, WebGL-платформа.

## Подключение в новую игру

1. **Закрепите версию пакета.** В `Packages/manifest.json` игры добавьте в `dependencies`:

   ```json
   "com.kirillpolosov.yg-core": "https://github.com/<владелец>/yg-core.git?path=/Packages/com.kirillpolosov.yg-core#v0.1.0"
   ```

   Адрес репозитория и версия подставляются актуальные. Всегда указывайте тег `#vX.Y.Z`, а не ветку: так версия закреплена в `packages-lock.json`.

   Пока репозиторий не опубликован, для разработки используйте локальный путь:

   ```json
   "com.kirillpolosov.yg-core": "file:/Users/kirillpolosov/yg-core/Packages/com.kirillpolosov.yg-core"
   ```

   Для выпускаемой игры локальный путь не используется.

2. **Подключите PluginYG2** той версии, что указана в `compatibility.md`. PluginYG2 не ставится как зависимость пакета автоматически: Unity не подтягивает git-зависимости транзитивно, поэтому его подключает игра.

3. **Define-символы.** Модули PluginYG2 включаются символами в Player Settings (WebGL). Набор, на котором проверяется пакет:

   `YandexGamesPlatform_yg; PLUGIN_YG_2; TMP_YG2; NJSON_YG2; EnvirData_yg; Authorization_yg; Storage_yg; Leaderboards_yg; InterstitialAdv_yg; RewardedAdv_yg; Payments_yg; Localization_yg; RU_YG2`

   Нужные игре модули выбираются по необходимости, но неиспользуемые модули PluginYG2 оставляйте выключенными.

4. **Подключите сервисы в одном месте на старте** игры через фабрики. Игровой код получает сервисы по контрактам и не вызывает PluginYG2 сам. Пример появится в рецептах после переноса модулей.

5. **Проверьте на дымовом тесте**: игра стартует в редакторе на моках, и в сборке WebGL показывается загрузочный экран и событие готовности.

## Обновление версии пакета в игре

Живые игры закреплены на проверенной версии. Обновляйте только по решению владельца.

1. Прочитайте записи версий между текущей и новой в [versions/](versions/), особенно раздел «Перенос для игр».
2. Поднимите тег в `manifest.json`.
3. Выполните пункты переноса из записей версий.
4. Соберите WebGL и пройдите дымовой тест игры на Яндексе (черновик в консоли).
5. Если менялась схема сохранений, проверьте загрузку сохранения со старой версией игры.

## Если что-то не работает

- Ошибки компиляции про `YG`/`PluginYG2`: версия PluginYG2 или define-символы не совпадают с `compatibility.md`.
- Игра не видит сервис: сервис не зарегистрирован через фабрики на старте.
- В редакторе нет рекламы или покупок: это ожидаемо, в редакторе работают моки.
