# Рецепты

Здесь лежат готовые сценарии «как сделать X» с рабочим кодом. Рецепт добавляется вместе с модулем, к которому относится.

Формат рецепта:

1. Задача одной строкой.
2. Что понадобится (модули, настройки консоли Яндекса).
3. Шаги с кодом (комментарии на русском).
4. Как проверить на стенде.
5. Типичные ошибки.

Планируемые рецепты: показать rewarded-рекламу, показать interstitial, добавить товар, добавить поле в сохранение и написать миграцию, отправить результат в лидерборд, добавить язык.
