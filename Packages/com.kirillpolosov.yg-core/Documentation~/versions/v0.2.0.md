# v0.2.0

Дата: 2026-10-13 · Тип: MINOR

## Что сделано

- Три новых контракта платформы в `YgCore.Contracts`: `IReviewService` (оценка игры), `IShortcutService` (ярлык игры), `IServerClock` (серверное время).
- Реализация для Яндекс Игр: `PluginYG2ReviewService`, `PluginYG2ShortcutService`, `PluginYG2ServerClock`. Работают через новый мост `YgPlatformFeaturesBridge` и `YgCorePlatformFeatures.jslib` прямыми вызовами SDK (`ysdk.feedback`, `ysdk.shortcut`, `ysdk.serverTime`). Модули `Review` и `ServerTime` PluginYG2 не нужны.
- Моки (`EditorMockReviewService`, `EditorMockShortcutService`, `EditorMockServerClock`), заглушки (`Unavailable*`) и фабрики (`ReviewServiceFactory`, `ShortcutServiceFactory`, `ServerClockFactory`).
- `CompositeLocalizationCatalog`: несколько каталогов строк (оболочка и игра) как один каталог для любого сервиса локализации. Вспомогательный интерфейс `ILocalizationCatalogLookup` реализован в `DictionaryLocalizationCatalog`.
- Исправление прогресса: слияние при входе не теряет награды и покупки, сделанные за время слияния.
- Исправление прогресса: громкость `NaN` больше не попадает в настройки и сохранение.
- Стенд: секции «Оценка и ярлык» и «Время», самопроверка «Составной каталог строк».
- Исправление, найденное при прогоне на площадке: файлы `YgPlatformFeaturesBridge.cs` и `Plugins/YgCorePlatformFeatures.jslib` не попали в первый коммит выпуска (глобальный `.gitignore` пользователя с правилом `*~` скрыл новые файлы в папке `YandexBridge~`); добавлены, в `.gitignore` репозитория исключение для `YandexBridge~`.
- `PluginYG2AdsService`: если платформа не открыла рекламу за 20 секунд (блокировщик, аккаунт без рекламы, молчание SDK), возвращается Error вместо ожидания трёх минут.
- Версия пакета `0.2.0` в `package.json`, решения DEC-024, DEC-025, DEC-026 в `Docs/DECISIONS.md`. Тег `v0.2.0` поставлен 2026-10-13 на коммит с этими исправлениями.

## Проверено

Прогон на Яндекс Играх выполнен владельцем 2026-10-13 в составе шаблона `yg-template-roblox` (черновик в консоли, сборка WebGL с пакетом на коммите `698ee3c`): оценка игры, ярлык, реклама с наградой, таблица лидеров, покупки, вход. Отдельная сборка стенда `yg-core` не выполнялась. Результат по `ysdk.serverTime()` отдельно не фиксировался: если у SDK функции нет, сервис недоступен и игра использует локальные часы.

## Зачем

Шаблон игр (`yg-template-roblox`) нуждается в окне оценки, ярлыке и серверном времени для ежедневной награды, а их надёжность нужна во всех играх, поэтому они принадлежат пакету (`09_PLATFORM_MODULES.md` шаблона). Составной каталог нужен, чтобы строки оболочки и игры жили раздельно, но отдавались сервису локализации одним каталогом (v0.1.1 принимал только один каталог). Два исправления закрывают пункты 1 и 2 раздела «Известные ограничения пакета v0.1.1» из `08_PROGRESSION.md` шаблона.

## Решения по сигнатурам

| Контракт | Метод | Значение результата |
|---|---|---|
| `IReviewService` | `bool IsPlatformAvailable` | у SDK есть `feedback.canReview` и `feedback.requestReview` |
| | `Task<PlatformServiceResult<bool>> CanReviewAsync()` | `Value`: можно показать окно; причина отказа в `Message` (`NO_AUTH`, `GAME_RATED`, `REVIEW_ALREADY_REQUESTED`, `REVIEW_WAS_REQUESTED`, `UNKNOWN`) |
| | `Task<PlatformServiceResult<bool>> RequestReviewAsync()` | `Value`: игрок оценил (`feedbackSent`) |
| `IShortcutService` | `bool IsPlatformAvailable` | у SDK есть `shortcut.canShowPrompt` и `shortcut.showPrompt` |
| | `Task<PlatformServiceResult<bool>> CanShowPromptAsync()` | `Value`: можно показать диалог (`canShow`) |
| | `Task<PlatformServiceResult<bool>> ShowPromptAsync()` | `Value`: игрок согласился (`outcome == accepted`) |
| `IServerClock` | `bool IsPlatformAvailable` | у SDK есть `serverTime` |
| | `Task<PlatformServiceResult<DateTime>> GetUtcNowAsync()` | серверное время UTC (`Kind == Utc`) |

События у новых контрактов нет. Сигнатуры совпадают с предложенными в `09_PLATFORM_MODULES.md` шаблона.

### Серверное время SDK

Подтверждено частично. Страницы официальной документации Яндекс Игр, доступные 2026-10-12 (SDK about, events, environment, review, shortcut), метод `ysdk.serverTime()` не описывают. Каталог модулей PluginYG2 (`Editor/ServerInfoYG2.json`) содержит модуль `ServerTime`, и его описание говорит, что время берётся с сервера Яндекса и отдаётся в миллисекундах Unix; в самом проекте модуль не установлен, исходников для сверки нет. Поэтому:

- мост вызывает `ysdk.serverTime()`, предварительно проверив `typeof ysdk.serverTime === 'function'`, и принимает как число, так и Promise;
- если функции нет, `IServerClock.IsPlatformAvailable == false`, `GetUtcNowAsync` возвращает `PlatformUnavailable`, и **запасной вариант (локальные часы UTC) выбирает игра**, пакет подмену не делает;
- единицы (миллисекунды) и сам факт наличия функции нужно подтвердить кнопкой «Серверное время» на стенде.

### Поддержка нескольких каталогов строк

В v0.1.1 её не было: `LocalizationServiceFactory`, мок, заглушка и `PluginYG2LocalizationService` принимают один `ILocalizationCatalog`. Теперь `new CompositeLocalizationCatalog(gameCatalog, shellCatalog)` отдаётся им как обычный каталог. На практике проверено в `Tools/CoreChecks` (через мок и заглушку локализации) и `Tools/YandexChecks` (через настоящий `PluginYG2LocalizationService`): строки обоих каталогов, приоритет первого каталога, русская строка второго каталога не перебивается английским запасным вариантом первого, три языка из разных каталогов, чужой каталог без `ILocalizationCatalogLookup`, ошибки конструктора. Живой сервис платформы проверяет кнопка стенда «Составной каталог строк».

## Перенос для игр

Изменений не требуется: старые контракты и формат сохранения не менялись, новые возможности необязательны.

Чтобы использовать новое:

1. Обновить тег пакета до `v0.2.0`. Мосты обновит установщик (в `Assets/YgCore/YandexBridge` появятся `YgPlatformFeaturesBridge.cs` и `YgCorePlatformFeatures.jslib`); папку игры закоммитить.
2. Получать сервисы через `ReviewServiceFactory.Create()`, `ShortcutServiceFactory.Create()`, `ServerClockFactory.Create()`.
3. Всегда вызывать `CanReviewAsync` (`CanShowPromptAsync`) перед показом окна и показывать окно только при `Value == true`.
4. Для серверного времени при результате не `Success` брать локальные часы UTC и считать их ненадёжными.
5. Если у игры несколько наборов строк, собрать их `CompositeLocalizationCatalog` (каталог игры первым).

Поведенческие изменения, о которых стоит знать: после слияния при входе в сохранении оказывается и то, что игрок получил во время слияния; `NaN` в громкости заменяется значением по умолчанию.

## Риски и известные ограничения

- Стенд в Unity не собирался, JavaScript-сторона (`YgCorePlatformFeatures.jslib`) и вызовы SDK на Яндексе не проверялись: проверены только имена (`check-jslib.py`) и C# с заглушкой PluginYG2. Сигнатуры SDK взяты из документации (оценка, ярлык) и из описания модуля плагина (серверное время).
- Документация ярлыка не перечисляет все значения `outcome`; согласием считается только `accepted`.
- Окно оценки платформа открывает не вошедшему игроку отказом (`NO_AUTH`) и принимает один запрос за сессию. Когда предлагать оценку, решает игра.
- Слияние при входе по-прежнему подчиняется `Merge` игры: при слиянии баланса максимумом награда гостя не суммируется с облачным значением (ограничение шаблона, `08_PROGRESSION.md`).
- Сбой облака при слиянии: запись удерживается, прогресс гостя не затирает облачный, слияние повторяется до 8 раз с интервалом `RetryDelay`, после успеха записывается итог (решение владельца принято, DEC-026). Если связи нет всю сессию, прогресс остаётся в памяти и не записывается.
- Пункт 3 ограничений шаблона (рост `processedPurchaseTokens`) относится к шаблону, не к пакету.
