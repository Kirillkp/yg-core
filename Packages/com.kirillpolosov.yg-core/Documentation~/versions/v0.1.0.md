# v0.1.0

Дата: 2026-10-10 · Тип: MINOR (первый рабочий выпуск)

## Что сделано

- Код всех модулей перенесён из «Обби Потоп» в пакет: Core, Contracts, Localization, Mocks, Factories, Yandex (+ мосты), Save, Store, Audio, WebQuality, `LocalizedTextView`.
- Пакет собран в Unity 6000.6.0f1 и проверен на стенде (`Stand/`) в консоли Яндекса.
- Мосты к PluginYG2 устанавливаются в проект игры редакторным установщиком (`Assets/YgCore/YandexBridge`), потому что скрипты пакета без `.asmdef` Unity в сборки игры не берёт (DEC-022).
- Очередь «одна операция за раз» в сервисах сохранения, покупок и `ProgressionService` реализована своим `AsyncGate` вместо `SemaphoreSlim`: в WebGL нет пула потоков (DEC-023).
- Звук: при рекламе, паузе платформы, покупке и потере фокуса останавливается весь звук, отсчёт `Countdown` звук не держит. Это исправление недосмотров «Обби».
- Документация: документ каждого модуля, подключение, архитектура, совместимость, заплатки PluginYG2, решения (`Docs/DECISIONS.md`).
- Проверки без Unity: 230 проверок `CoreChecks`, `YandexChecks`, согласованность C# и JavaScript, образцов кода в документации и `.meta`.

## Зачем

Общая механика Яндекс Игр (реклама, вход, покупки, сохранения, звук, язык, лидерборд, пауза) в одном версионируемом пакете, который подключается к играм по git-тегу, вместо копирования кода из проекта в проект.

## Перенос для игр

- **Новые игры:** подключите пакет по тегу `v0.1.0` (`Documentation~/install.md`). При первой загрузке редактора установщик создаст `Assets/YgCore/YandexBridge`: закоммитьте эту папку. В сцене нужен `AudioListener`. Нужен PluginYG2 v2.0092 и define-символы из `install.md`.
- **«Обби Потоп»:** остаётся на своём коде. Переключение на пакет не выполнялось и выполняется отдельным решением владельца по плану `Docs/MIGRATION_FROM_OBBY.md`. При переключении собственные мосты игры заменяет установщик, а звук меняется намеренно (см. «Что сделано»).

## Риски и известные ограничения

- На стенде не проверены: пауза по фокусу вкладки отдельной причиной `Focus`, слух (музыка и пауза звука на рекламе), сбой загрузки сохранения как «не пустое сохранение», миграция схемы сохранения, веб-качество на устройствах, `LocalizedTextView` на настоящем uGUI, `ProgressionService` и `SessionStoreService` на живой платформе (проверены сервисы под ними). Всё это покрыто только проверками без Unity.
- Решения DEC-008..010, 012..014, 016..019, 021, 022, 023 в статусе «предложено»: владелец их ещё не принял явно.
- Товар `stand_consumable` в консоли отдаётся как `расходуемый=False`: для проверки гашения это не мешает, но признак в консоли стоит проверить.
- Необязательная сборка `YgCore.Audio.UI` (uGUI и Input System) в стенде не включалась.
