# Модуль: Аудио

Сборки: `YgCore.Audio` и необязательная `YgCore.Audio.UI` · Пространства имён: `YgCore.Audio`, `YgCore.Audio.UI` · С версии: `v0.1.0` · Статус: перенесён из «Обби Потоп», проверен вне Unity на заглушках; на стенде на Яндексе директор работает: музыка запускается, реклама ставит и снимает паузу (на слух проверяет владелец)

`YgCore.Audio` зависит от `YgCore.Core`. `YgCore.Audio.UI` подключается сама только если в проекте есть uGUI и Input System.

## Зачем нужен

Звук в играх для Яндекса должен вести себя одинаково правильно: останавливаться на время рекламы, покупки и потери фокуса, слушаться ползунков громкости игрока, не превращать десять одинаковых звуков за кадр в треск. Модуль решает это один раз. Что именно звучит в игре (бег, монеты, вода), знает только игра.

> **Нужен `AudioListener` в сцене.** Директор создаёт источники звука, но слушателя не добавляет: в собранной WebGL-игре без `AudioListener` (обычно он на главной камере) звука нет совсем. В редакторе звук слышен и без него через окно Scene, поэтому ошибка видна только в сборке. Найдено на стенде.

## Что делает пакет и что делает игра

| Пакет (общее) | Игра (своё) |
|---|---|
| Две шины: музыка и эффекты, громкость из настроек игрока с кривой | Какие клипы, какие звуки, их идентификаторы (enum) |
| Пул голосов для эффектов (по кругу), ограничение частоты, разброс тона | На какие события игры какой звук играть |
| Музыка: запуск, пауза по настройке, приглушение на паузе и экране результата | Правила выбора звука для кнопок по имени |
| Заставка на экране результата | Что делает музыку быстрее при опасности |
| Полная остановка всего звука при рекламе, платформе, покупке, фокусе (отсчёт звук не держит) | Какие зацикленные звуки оставить на экране результата |
| Зацикленные звуки: старт, стоп, гашение на паузе игрока | |
| Звук нажатия для переключателей и ползунков (`UiPressSounds`) | |

## Как это устроено

`AudioDirector` это базовый компонент (MonoBehaviour) для сцены. Игра **наследует** его, подписывается на свои события в `OnInitialized` и вызывает `Play`, `StartLoop`, `StopLoop`. Идентификаторы звуков это числа: игра задаёт их своим `enum` и приводит к `int`. Список звуков и клипы настраиваются в инспекторе.

### Громкость

Громкость шины = `громкость игрока ^ кривая * база`, где кривая по умолчанию 1,5 (середина ползунка звучит заметно тише линейной), база для музыки 0,7 и для эффектов 0,45. Выключенная шина даёт 0. Эти значения задаются в инспекторе директора.

### Пауза

| Причина паузы | Что происходит со звуком |
|---|---|
| Пауза игрока (`User`) | Музыка тише (множитель 0,4), эффекты и зацикленные звуки идут. Зацикленные с пометкой «гасить на паузе игрока» затихают |
| Реклама, платформа, покупка, фокус (`Ad`, `Platform`, `Purchase`, `Focus`) | Ставится пауза слушателя (`AudioListener.pause`): **весь звук останавливается**: музыка, заставка, эффекты и зацикленные. Новые эффекты в это время не запускаются |
| Отсчёт (`Countdown`) | Звук **не останавливает**: музыка возвращается сразу, как только закрылась реклама, а отсчёт идёт параллельно |

> **Пауза игрока не затрагивает слушателя**, поэтому звуки кнопок в меню паузы работают. Останавливается звук только по причинам платформы: реклама, окно платформы, покупка, потеря фокуса.

> **Настройка `silenceEffectsOnHardPause`** (в инспекторе директора, по умолчанию **включена**). Если её выключить, эффекты и зацикленные звуки игнорируют паузу слушателя и продолжают звучать во время рекламы и пауз платформы, а останавливается только музыка. Нужно редко: например, если эффекты должны звучать поверх окна платформы.

### Состояния

Музыка запускается при входе в любое состояние, кроме `Result`. На `Result` включается заставка (один раз) и музыка приглушается до 0,25. При смене состояния зацикленные звуки останавливаются, кроме тех, которые наследник оставил через `KeepLoopOnResult` для состояния `Result`.

## Подключение

Ниже рабочий образец игрового наследника (этот код компилируется и выполняется в `Tools/CoreChecks`).

```csharp
using System;
using UnityEngine;
using YgCore.Audio;
using YgCore.Core;

// Идентификаторы звуков задаёт игра своим enum. Числа попадают в настройки директора в сцене.
public enum SampleSfx
{
    Click = 0,
    Coin = 1,
    Hit = 2,
    Splash = 3,
    DangerLoop = 100,
    BubblesLoop = 101
}

// События игры, на которые реагирует звук. В настоящей игре это её сервисы (бегун, монеты, вода).
public sealed class SampleGameEvents
{
    public event Action CoinCollected;
    public event Action<int> LivesChanged;
    public event Action<bool> Flooded;

    public bool IsFinalFlood { get; set; }
    public bool IsDanger { get; set; }

    public void RaiseCoin() => CoinCollected?.Invoke();
    public void RaiseLives(int lives) => LivesChanged?.Invoke(lives);
    public void RaiseFlood(bool isFinal) => Flooded?.Invoke(isFinal);
}

public sealed class SampleAudioDirector : AudioDirector
{
    private SampleGameEvents game;
    private int lastLives = 3;
    private float coinPitch = 1f;
    private float lastCoinTime = -10f;

    // Свой Initialize принимает сервисы игры и вызывает базовый.
    public void Initialize(
        IGameplayStateService state,
        IPauseCoordinator pause,
        IGameSettingsService settings,
        SampleGameEvents gameEvents)
    {
        game = gameEvents;
        Initialize(state, pause, settings);
    }

    // Подписка на события игры. Вызывается базовым классом при инициализации.
    protected override void OnInitialized()
    {
        game.CoinCollected += OnCoin;
        game.LivesChanged += OnLives;
        game.Flooded += OnFlooded;
    }

    protected override void OnDestroy()
    {
        if (game != null)
        {
            game.CoinCollected -= OnCoin;
            game.LivesChanged -= OnLives;
            game.Flooded -= OnFlooded;
        }

        base.OnDestroy();
    }

    // При входе в забег сбрасываем счётчик жизней.
    protected override void OnAppStateEntered(AppState state)
    {
        if (state == AppState.Run)
        {
            lastLives = 3;
        }
    }

    // При финальном затоплении пузыри продолжают звучать на экране результата.
    protected override bool KeepLoopOnResult(int loopId)
    {
        return loopId == (int)SampleSfx.BubblesLoop && game.IsFinalFlood;
    }

    // В момент опасности музыка чуть ускоряется, но только во время забега.
    protected override float GetMusicPitch()
    {
        return game != null && game.IsDanger && StateService.CurrentState == AppState.Run ? 1.06f : 1f;
    }

    private void OnCoin()
    {
        // Цепочка монет повышает тон, пауза в 0,9 секунды сбрасывает цепочку.
        coinPitch = Time.unscaledTime - lastCoinTime < 0.9f ? Mathf.Min(coinPitch + 0.06f, 1.5f) : 1f;
        lastCoinTime = Time.unscaledTime;
        Play((int)SampleSfx.Coin, coinPitch);
    }

    private void OnLives(int lives)
    {
        if (lives < lastLives)
        {
            Play((int)SampleSfx.Hit);
            if (lives == 1)
            {
                StartLoop((int)SampleSfx.DangerLoop);
            }
        }

        lastLives = lives;
    }

    private void OnFlooded(bool isFinal)
    {
        if (isFinal)
        {
            Play((int)SampleSfx.Splash);
            StartLoop((int)SampleSfx.BubblesLoop);
            StopLoop((int)SampleSfx.DangerLoop);
        }
    }
}
```

В сцене: повесить `SampleAudioDirector` (ваш наследник) на объект, в инспекторе добавить музыку, заставку, список звуков (`Sfx`) и зацикленных (`Loops`). На старте один раз:

```csharp
audioDirector.Initialize(gameplayStateService, pauseCoordinator, gameSettingsService, gameEvents);
```

### Звуки нажатия на интерфейс

Если в проекте есть uGUI и Input System, добавьте на сцену компонент `UiPressSounds` (сборка `YgCore.Audio.UI`) и подключите его к директору. В инспекторе задаются звуки переключателя, ползунка и общий звук нажатия. Правила игры для отдельных кнопок (например, по имени) задаются через `Resolver`:

```csharp
uiPressSounds.Initialize(audioDirector);
uiPressSounds.Resolver = selectable => selectable.gameObject.name == "Close"
    ? (int)MySfx.Close
    : UiPressSounds.NoSound;   // NoSound: использовать общий звук
```

Без uGUI или Input System компонента нет: звуки интерфейса игра включает сама, вызывая `audioDirector.Play(...)`.

### Звуки магазина

Модуль Audio не зависит от Store. Связь пишет игра: подпишитесь на `store.StatusChanged` и играйте нужные звуки.

```csharp
store.StatusChanged += status =>
{
    if (status == StoreStatus.Success) Play((int)MySfx.Purchase);
};
```

## Публичный API

### `AudioDirector`

| Что | Назначение |
|---|---|
| `Initialize(state, pause, settings)` | Подключение к сервисам Core. Один раз, повтор игнорируется. Наследник вызывает его из своего `Initialize` |
| `Play(id, pitch)` | Эффект. Молчит, если эффекты выключены, звука нет или он играл раньше интервала |
| `StartLoop(id)`, `StopLoop(id)`, `IsLoopPlaying(id)` | Зацикленные звуки |
| `PlayedRecently(id, window)` | Играл ли звук за последние секунды |
| `OnInitialized()` | Точка подписки на события игры |
| `OnAppStateEntered(state)` | Реакция на смену состояния (например, сброс счётчиков). Вызывается до остановки зацикленных звуков |
| `KeepLoopOnResult(loopId)` | Оставить ли зацикленный звук на экране результата |
| `GetMusicPitch()` | Высота тона музыки (по умолчанию 1) |
| `ApplyVolumes()`, `MusicVolume()`, `SfxVolume()` | Применение и расчёт громкости (для наследников) |
| `OnDestroy()` | Наследник вызывает `base.OnDestroy()` после своей отписки |

### Помощники

| Что | Назначение |
|---|---|
| `AudioPolicy` | Чистые правила: громкость шины, приглушение музыки, «жёсткая» пауза |
| `SfxThrottle` | Ограничитель частоты эффектов |
| `AudioSettingsApplier` | Подчиняет настройкам игрока источники звука, лежащие прямо в сцене |
| `UiPressSounds` | Звук нажатия на элементы uGUI (необязательная сборка) |

## Правила

- Игровой код звук напрямую не включает: события игры слушает наследник директора.
- Идентификаторы звуков (числа) попадают в сцену и префабы, после выпуска игры их менять нельзя.
- Если переопределяете `OnDestroy`, вызывайте `base.OnDestroy()`: он снимает глобальную паузу звука.
- Источник звука всех эффектов создаётся самим директором, отдельные `AudioSource` для эффектов в сцене не нужны.

## Чего делать нельзя

- Вызывать `AudioListener.pause` самостоятельно: паузу звука ведёт директор по причинам паузы.
- Подписываться на события игры в `Awake`: источников звука ещё нет. Используйте `OnInitialized`.
- Класть в сцену два директора.

## Как проверить

Без Unity: `dotnet run --project Tools/CoreChecks`. Для Audio там 59 проверок на заглушках Unity, где источник звука запоминает всё, что с ним делают, и реальный код директора выполняется: правила громкости и паузы, ограничитель частоты, голоса по кругу, музыка и настройки, заставка результата, пауза от рекламы и платформы, отсчёт, цепочка монет, зацикленные звуки и их остановка, подчинение источников сцены настройкам и звуки интерфейса. Главные правила проверены «мутациями»: если сломать жёсткую паузу, вернуть отсчёт в жёсткую паузу, разрешить эффекты во время рекламы, убрать ограничитель частоты или гашение на паузе игрока, проверки падают.

На стенде (секция «Пауза»): музыка идёт, реклама останавливает **весь** звук (в том числе зацикленные), музыка возвращается сразу после закрытия рекламы, не дожидаясь отсчёта, свёрнутая вкладка и пауза платформы останавливают звук. **Не проверено в Unity:**

- настоящие `AudioSource` и `AudioListener` (в проверках их заменяют заглушки);
- сборка `YgCore.Audio.UI` (необязательная): что Unity правильно включает её по `defineConstraints` и `versionDefines` и не жалуется на отсутствующие ссылки, когда uGUI или Input System нет.

## Отличия от «Обби Потоп»

- Один класс `AudioDirector` на 519 строк разделён: общий механизм в пакете, события «Обби» (бегун, монеты, брейнроты, жизни, вода, магазин, экономика) переезжают в игровой наследник.
- Идентификаторы звуков числа (`int`), а не enum `SfxId`. Enum остаётся в игре и приводится к `int`.
- Два зацикленных звука «Обби» (опасность и пузыри) стали общим списком `Loops` с `StartLoop`/`StopLoop`. Громкости 0,55 и 0,7 и «гасить на паузе игрока» для опасности настраиваются в записи, а не зашиты в код.
- Приглушение музыки (0,25 и 0,4) стало настройкой инспектора с теми же значениями по умолчанию.
- Определение звука кнопки по имени (`Play`, `Close`, `Shop`) убрано из пакета: правила задаёт игра через `UiPressSounds.Resolver`.
- Звуки нажатия вынесены в необязательную сборку, чтобы пакет не требовал uGUI и Input System.
- Игра, которая слушала `store.StatusChanged` как строку, теперь слушает `StoreStatus` (модуль Store).
- **Исправлены два поведения «Обби Потоп», которые были недосмотром:** (1) при рекламе, паузе платформы, покупке и потере фокуса останавливалась только музыка, а эффекты и зацикленные звуки (например, «опасность») продолжали играть; теперь останавливается весь звук (настройка `silenceEffectsOnHardPause`, по умолчанию включена); (2) музыка молчала весь отсчёт «3-2-1» после рекламы; теперь отсчёт звук не останавливает и музыка возвращается сразу.
- Громкость, пул голосов, ограничитель частоты, приглушение музыки и заставка перенесены без изменений.
- Комментарии на русском.

Как перевести «Обби» на модуль, см. `Docs/MIGRATION_FROM_OBBY.md` (раздел «Переключение Обби»).
