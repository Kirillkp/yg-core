# Модуль: Core

Сборка: `YgCore.Core` · Пространство имён: `YgCore.Core` · С версии: `v0.1.0` (пока в разделе Unreleased) · Статус: перенесён из «Обби Потоп»

Зависимостей от других сборок пакета нет. Использует только `UnityEngine` (`Mathf`, в WebGL ещё `Time` и `Awaitable`).

## Зачем нужен

Основа любой игры: в каком она состоянии (меню, игра, пауза, результат), кто и почему поставил её на паузу, сколько у игрока валюты и какие у него настройки звука. Модуль не знает ни про Яндекс, ни про конкретную игру.

## Когда использовать

- Нужно единое состояние приложения и события его смены.
- Нужна пауза, на которую влияют несколько источников (игрок, реклама, покупка, платформа, потеря фокуса).
- Нужна валюта с защитой от двойного начисления.
- Нужны настройки громкости музыки и звуков.

## Когда не использовать

- Хранение между запусками: это делает модуль сохранений (`Save`), Core хранит всё только в памяти сессии.
- Игровые правила (жизни, очки, сложность): они остаются в игре.

## Подключение

Экземпляры создаёт сборка игры один раз на старте и передаёт зависимым классам.

```csharp
using YgCore.Core;

// Один координатор паузы на всё приложение.
var pause = new PauseCoordinator();

// Состояние приложения связано с паузой: подписывается на неё само.
var state = new GameplayStateService(pause);

// Валюта и настройки живут в памяти сессии.
var economy = new SessionEconomyService();
var settings = new SessionGameSettingsService();

// Загрузка закончилась: Boot -> Menu.
state.CompleteBoot();
```

## Состояния и переходы

`GameplayStateService` управляет состоянием `AppState`:

| Вызов или событие | Из | В | Замечание |
|---|---|---|---|
| `CompleteBoot()` | Boot | Menu | |
| `StartRun()` | Menu | Run | Без отсчёта: переход из меню анимирует сама игра |
| `StartRun()` | Result или другое не меню | Pause, затем Run | Ставится причина `Countdown`, после её снятия идёт Run |
| Любая причина паузы | Run | Pause | Геймплей останавливается |
| Все причины сняты | Pause | Pause, затем Run | Сначала ставится `Countdown`, после её снятия идёт Run |
| `FinishRun()` | любое | Result | Снимает `Countdown` |
| `ReturnToMenu()` | любое | Menu | Снимает `Countdown` |

### Обязательное правило про `Countdown`

Сервис сам ставит причину `PauseReason.Countdown` при перезапуске и при каждом возобновлении после паузы. **Снимать её должен слой игры, когда закончился отсчёт «3-2-1».** Если её не снять, игра навсегда останется в состоянии Pause.

Если отсчёт игре не нужен, достаточно снимать `Countdown` сразу, как только она появилась (подпишитесь на `IPauseCoordinator.PauseChanged` и вызовите `ReleasePause(PauseReason.Countdown)`).

## Публичный API

### Пауза

| Что | Назначение | Замечания |
|---|---|---|
| `IPauseCoordinator.RequestPause(reason)` | Добавить причину | Ровно один флаг, иначе `ArgumentException`. Повтор ничего не меняет |
| `IPauseCoordinator.ReleasePause(reason)` | Снять причину | Если причины не было, ничего не происходит |
| `IPauseCoordinator.ClearAll()` | Снять все причины | |
| `IPauseCoordinator.IsPaused`, `ActiveReasons`, `HasReason(reason)` | Состояние паузы | |
| `IPauseCoordinator.PauseChanged` | Событие изменения набора причин | Только при реальном изменении |

Причины: `User`, `Platform`, `Ad`, `Purchase`, `Focus`, `Countdown`.

### Состояние

| Что | Назначение |
|---|---|
| `IGameplayStateService.CurrentState` | Текущий `AppState` |
| `IGameplayStateService.IsGameplayActive` | Идёт ли активный геймплей (Run и нет паузы) |
| `StateChanged` | Смена состояния |
| `GameplayActivityChanged` | Геймплей начался или остановился. По нему сообщать платформе |
| `CompleteBoot()`, `StartRun()`, `FinishRun()`, `ReturnToMenu()` | Переходы |
| `NotifyGameplayStarted()`, `NotifyGameplayStopped()` | Явное включение или выключение активности |

### Экономика

| Что | Назначение | Замечания |
|---|---|---|
| `IEconomyService.TryCredit(id, amount, reason)` | Начислить | `false`: сумма не больше нуля, пустой id или такой id уже был |
| `IEconomyService.TrySpend(id, amount, reason)` | Списать | Дополнительно `false`, если денег не хватает |
| `IEconomyService.HasProcessed(id)` | Была ли транзакция | |
| `IEconomyService.Balance`, `BalanceChanged` | Баланс и событие | Баланс не бывает отрицательным |
| `SessionEconomyService.RestoreBalance(balance)` | Восстановить из сохранения | Это не транзакция. Отрицательное значение становится нулём |

Журнал обработанных транзакций живёт только в текущей сессии. Защита от повторного начисления между запусками, если она нужна, делается на уровне сохранений.

### Настройки звука

| Что | Назначение |
|---|---|
| `IGameSettingsService.IsMusicEnabled`, `IsSfxEnabled`, `MusicVolume`, `SfxVolume` | Текущие значения. Громкость от 0 до 1 |
| `SetMusicEnabled`, `SetSfxEnabled`, `SetMusicVolume`, `SetSfxVolume` | Изменение. Значения громкости ограничиваются диапазоном 0–1. Событие только при реальном изменении |
| `SessionGameSettingsService.Restore(...)` | Установка всех значений из сохранения. Событие приходит всегда |
| `SessionGameSettingsService(music, sfx)` | Свои стартовые громкости. Без параметров: музыка 0.5, эффекты 0.1 |

### Прочее

| Что | Назначение |
|---|---|
| `RealtimeDelay.Delay(TimeSpan, CancellationToken)` | Задержка в реальном времени, не зависит от паузы. В WebGL ждёт по кадрам, потому что в браузере нет потоков-таймеров. Используется для таймаутов запросов к платформе |

## События и ошибки

| Событие или ошибка | Когда возникает | Что делать |
|---|---|---|
| `ArgumentException` из `RequestPause`/`ReleasePause`/`HasReason` | Передан `None` или несколько флагов | Передавать ровно одну причину |
| `OverflowException` из `TryCredit` | Баланс выйдет за пределы `int` | Ограничивать начисления в игре |
| `ArgumentNullException` в `GameplayStateService` | Не передан координатор паузы | Создавать координатор раньше сервиса |

## Чего делать нельзя

- Менять баланс мимо `IEconomyService`.
- Писать в сохранение из интерфейса напрямую.
- Забывать снимать `PauseReason.Countdown` (игра зависнет на паузе).
- Передавать составные флаги в методы паузы.

## Как проверить

- Логика паузы, экономики, состояний и настроек проверяется без Unity: `dotnet run --project Tools/CoreChecks` (193 проверки вместе с остальными модулями; на Core приходится 25).
- На стенде (секция «Пауза»): музыка встаёт на паузу при рекламе и возвращается после неё. Секция появится вместе со стендом.

## Отличия от «Обби Потоп»

- Пространство имён `ObbyPotop.Core` заменено на `YgCore.Core`, сборка называется `YgCore.Core`.
- У `SessionGameSettingsService` добавлен конструктор со стартовыми громкостями. Значения по умолчанию прежние (0.5 и 0.1), поведение без аргументов не изменилось.
- Текст исключения в `PauseCoordinator` переведён на русский.
- Остальное перенесено без изменений поведения.
