# Проверки логики без Unity

Быстрая проверка чистой логики пакета (пауза, экономика, переходы состояний, настройки) обычным `dotnet`, без запуска Unity. Компилирует исходники пакета вместе с заглушкой `UnityEngine.Mathf`, поэтому заодно проверяет, что код собирается и что ссылки в XML-документации корректны.

```bash
dotnet run --project Tools/CoreChecks
```

Ожидаемый результат: `Все проверки пройдены.` и код выхода 0.

Что не проверяется: всё, что требует Unity (WebGL-ветки, MonoBehaviour, PluginYG2). Это проверяет стенд.

Новая логика в пакете должна получать проверки здесь, если её можно проверить без Unity.
