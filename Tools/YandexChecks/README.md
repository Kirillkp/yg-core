# Проверки Яндекс-модуля без Unity

Реальные мосты (`Runtime/YandexBridge`) и сервисы (`Runtime/Yandex`) компилируются вместе с заглушками PluginYG2 и Unity (`Stubs.cs`). Сервисы находят мост и «PluginYG2» через рефлексию, как в игре, поэтому проверяется вся цепочка: событие PluginYG2 → мост → сервис → результат для игры.

```bash
dotnet run --project Tools/YandexChecks
```

Ожидаемый результат: `Все проверки пройдены.` и код выхода 0.

Дополнительно проверяется компиляция ветки WebGL (внешние функции `DllImport`, ожидающие `.jslib`):

```bash
dotnet build Tools/YandexChecks -p:WebGLCompile=true
```

Согласованность имён между C# и JavaScript (функции `.jslib` и методы `YGSendMessage`) проверяет `python3 Tools/check-jslib.py`.

## Что не проверяется

- Настоящий PluginYG2 и настоящая платформа: заглушки повторяют только то, что нужно мостам. Реальное поведение проверяет стенд на Яндексе.
- Ветка WebGL в работе (JavaScript-сторона покупок и хранилища): только компиляция.
- Успешные покупки и сохранение: им нужен JavaScript. Проверяются сбои и то, что блокировки не зависают.
