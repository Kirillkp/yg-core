# Тестовый стенд

Unity-проект стенда: экран с кнопками и журналом, который проверяет пакет прямо в консоли Яндекса. Это не игра.

Статус: **подготовлен к сборке под Яндекс, в консоли ещё не проверялся**. Секции: готовность и геймплей, реклама, авторизация, лидерборд, покупки, звук (с паузой на рекламу), самопроверки сохранения и языка. Нет проверок паузы по фокусу вкладки, возврата невыданной покупки, сбоя загрузки сохранения и миграции схемы, веб-качества (следующий срез). Правило: функция пакета не считается готовой, пока её нельзя проверить на стенде.

## Как открыть

В Unity Hub добавьте папку `Stand/` (не корень репозитория) и откройте её. Пакет подключается локально: `file:../../Packages/com.kirillpolosov.yg-core`. Сцена для запуска в редакторе не нужна: экран создаётся сам при старте (`StandBootstrap`). В редакторе стенд работает на моках.

## Что внутри

- `Assets/PluginYourGames/` — PluginYG2 v2.0092 (лицензия CC0), скопирован из «Обби Потоп». Единственная доработка: сообщение о закрытии окна входа `YgCoreAuthDialogClosed` (см. `Documentation~/patches/pluginyg2-auth-dialog-closed.md`).
- `Assets/WebGLTemplates/YandexGames/` — нейтральный шаблон страницы: объекты `window.YgLoading` и `window.YgWebQuality`, которые ждёт пакет.
- `Assets/link.xml` — защита PluginYG2 от обрезки кода (сервисы пакета обращаются к нему по имени).
- `Assets/Stand/Scripts/` — сам стенд: `StandApp` (вызовы контрактов), `StandBootstrap` (экран на UI Toolkit), `StandLog` (журнал OK/FAIL), `StandAudio` (настоящий `AudioDirector` с сгенерированными звуками).
- `Assets/Stand/Scripts/Editor/StandBuild.cs` — меню «YgCore Stand»: подготовка и сборка WebGL.

## Сборка и проверка на Яндексе

1. Меню **YgCore Stand → 1. Подготовить WebGL**: define-символы PluginYG2, шаблон, обрезка кода, сцена, переключение платформы.
2. Меню **YgCore Stand → 2. Собрать WebGL**. Результат: `Stand/Builds/WebGL` (архив для консоли создаёт PluginYG2).
3. В консоли Яндекса: черновик игры, товары `stand_consumable` (расходуемый) и `stand_permanent` (постоянный), таблица лидеров `stand`. Загрузить архив как черновик и открыть «Тестирование».
4. Пройти `Docs/STAND_CHECKLIST.md`. На экране стенда сначала должен идти список «Платформа: доступна» у всех сервисов.
