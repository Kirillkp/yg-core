# Тестовый стенд

Unity-проект стенда: экран с кнопками и журналом, который проверяет пакет прямо в консоли Яндекса. Это не игра.

Статус: **первый срез написан, в Unity не открывался**. Есть секции: готовность и геймплей, реклама, авторизация, лидерборд, покупки, самопроверки сохранения и языка. Нет секций паузы/аудио и веб-качества (следующий срез). Правило: функция пакета не считается готовой, пока её нельзя проверить на стенде.

## Как открыть

В Unity Hub добавьте папку `Stand/` (не корень репозитория) и откройте её. Пакет подключается локально: `file:../../Packages/com.kirillpolosov.yg-core`. Сцена не нужна: экран создаётся сам при старте (`StandBootstrap`).

## Устройство

- `StandApp` вызывает фабрики пакета, как это делает игра, и по одной кнопке на контракт.
- `StandLog` пишет `OK`/`FAIL` для самопроверок и показывает их на экране.
- `StandBootstrap` строит интерфейс на UI Toolkit (без uGUI и Input System).
- `StandVersion` и `Editor/StandVersionStamp` показывают версию пакета, в том числе в WebGL.

## Для проверки на Яндексе

Нужно поставить в стенд PluginYG2 v2.0092 и define-символы из `Documentation~/install.md` (PluginYG2 в репозиторий не коммитится). Затем собрать WebGL, загрузить черновик в консоль и пройти `Docs/STAND_CHECKLIST.md`.
