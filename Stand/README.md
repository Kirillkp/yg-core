# Тестовый стенд

Здесь будет Unity-проект стенда: сцена с кнопками и логом, которая проверяет пакет прямо в консоли Яндекса. Это не игра.

Статус: **проект ещё не создан**. Создание требует запущенного Unity Editor и делается отдельной задачей по просьбе владельца.

План:

- Проект подключает пакет локально: `"com.kirillpolosov.yg-core": "file:../../Packages/com.kirillpolosov.yg-core"`.
- Одна сцена. Секции: пауза, реклама, покупки, сохранение, авторизация, лидерборд, язык, готовность. См. `Docs/STAND_CHECKLIST.md`.
- Интерфейс стенда простой (кнопки и лог), он не использует игровой UI.
- На экране видна версия пакета.
- Часть проверок самопроверяющиеся: стенд сам пишет OK или FAIL.
- Сборка WebGL, загрузка черновика в консоль Яндекса вручную.
