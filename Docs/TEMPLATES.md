# Шаблоны игр

План, структура и очередь задач шаблонов (`yg-template-empty`, `yg-template-roblox`) перенесены в репозиторий `Kirillkp/yg-template` (`Docs/TEMPLATES.md`): пакет `yg-core` подходит любым играм и не описывает шаблоны. Оркестрация агентов остаётся здесь: [ORCHESTRATION.md](ORCHESTRATION.md).
