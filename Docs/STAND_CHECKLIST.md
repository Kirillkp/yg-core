# Чек-лист стенда на Яндексе

Стенд (`Stand/`) это отдельный проект без геймплея: сцена с кнопками и логом, на которой пакет проверяется прямо в консоли Яндекса. Чек-лист проходится перед каждым тегом версии. Часть проверок стенд выполняет сам и пишет OK или FAIL в лог.

Статус стенда: **создан** (`Stand/`, вкладки по секциям), прогон на Яндексе для v0.1.0 пройден 2026-10-10. Для v0.2.0 добавлены секции «Оценка и ярлык», «Время» и самопроверка «Составной каталог строк» (в Unity не собирались, на Яндексе не прогонялись). Не покрыты: пауза по фокусу отдельной причиной, слух, сбой загрузки сохранения, миграция схемы, веб-качество. Секции появляются вместе с модулями. Правило: функция пакета не считается готовой, пока её нельзя проверить на стенде.

## Подготовка в консоли

- Черновик игры со сборкой стенда загружен.
- Заведены тестовые товары (расходуемый и постоянный) и таблица лидерборда.
- Версия пакета на экране стенда совпадает с проверяемой.
- Сервисы Яндекс-модуля видят PluginYG2 и мосты: у каждого `IsPlatformAvailable == true` на платформе. Если нет, мосты не установлены в `Assets/YgCore/YandexBridge` (установщик пакета) или не сработали define-символы PluginYG2.
- В сборке нет ошибок обрезки кода (IL2CPP stripping): сервисы обращаются к PluginYG2 по имени.

## Секции

| Секция | Проверка | Автоматически |
|---|---|---|
| Пауза | Музыка играет. Показ рекламы ставит её на паузу, после закрытия она возвращается. Свёрнутая вкладка и пауза платформы тоже ставят паузу | частично |
| Реклама | Interstitial показывается и закрывается. Rewarded: награда выдаётся только после полного просмотра, при закрытии раньше не выдаётся. Ошибка или блокировка рекламы не ломает игру | нет |
| Покупки | Список товаров. Покупка. Повторная покупка расходуемого. Невыданная покупка возвращается при следующем запуске. Закрытие вкладки между оплатой и выдачей награды не теряет покупку | частично |
| Сохранение | Запись и чтение. Сбой загрузки не превращается в пустое сохранение. Две быстрые записи подряд сохраняются в правильном порядке. Загрузка сохранения старой схемы проходит миграцию | да |
| Авторизация | Гость, вход, выход, повторный запуск | нет |
| Лидерборд | Отправка результата, чтение топа и своего места | нет |
| Язык | Язык платформы определяется и применяется. Кнопка «Составной каталог строк»: строки двух каталогов в одном сервисе, приоритет и запасной язык | да |
| Оценка и ярлык | «Проверить сервисы»: у оценки и ярлыка `IsPlatformAvailable == true`. «Оценка: можно ли» и «Ярлык: можно ли» дают ответ без ошибки (гость получает `false` с причиной `NO_AUTH` в журнале). Для вошедшего игрока окно оценки открывается и в журнал попадает исход (оценил или закрыл). Диалог ярлыка открывается там, где платформа это разрешает (компьютер, ещё не добавлен), согласие и отказ различаются в журнале | частично |
| Время | «Серверное время»: либо время сервера и разница с локальным в пределах суток, либо запись «серверного времени нет» (тогда зафиксировать в записи версии, что у SDK нет `ysdk.serverTime()`) | частично |
| Готовность | Платформа получает событие готовности и начала геймплея | нет |
| Документация | Для проверяемых изменений обновлены модульные документы и CHANGELOG | нет |

## Результат

После прохода результат записывается в `Documentation~/versions/vX.Y.Z.md`, раздел «Проверено на стенде»: дата, окружение, что проверено, итог.
