# Соглашения по коду и документам

## Язык

- **Комментарии в коде только на русском.** Это требование заказчика: он читает код и должен понимать, что и зачем сделано. Комментируйте смысл и причину («зачем»), а не пересказывайте строку кода.
- XML-документация (`/// <summary>`) тоже на русском.
- Имена типов, методов, полей, файлов и пространств имён английские.
- Документы в репозитории на русском. Сообщения коммитов на английском в формате Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`).
- Тексты для игроков живут в данных игры, а не в пакете.

Пример комментария:

```csharp
// Пауза снимается только когда сняты ВСЕ причины: иначе реклама
// могла бы возобновить игру, пока пользователь ещё держит паузу.
```

## Пространства имён и сборки

- Корень: `YgCore`. Модули: `YgCore.Core`, `YgCore.Contracts`, `YgCore.Save`, `YgCore.Store`, `YgCore.Audio`, `YgCore.Localization`, `YgCore.WebQuality`, `YgCore.Mocks`, `YgCore.Yandex`, `YgCore.Factories`.
- Имя сборки (`.asmdef`) совпадает с корневым пространством имён модуля.
- Правила зависимостей: `Documentation~/architecture.md`. Не добавляйте ссылок, которых там нет.
- Нет упоминаний конкретных игр («Obby» и т.п.) в именах и тексте пакета.

## Платформенный код

- Все обращения к PluginYG2 и SDK только в `YgCore.Yandex`.
- Условная компиляция по define-символам PluginYG2 (`Payments_yg`, `Storage_yg` и т.д.) только в `YgCore.Yandex`.
- Всё, что меняет состояние на платформе (сохранение, покупка), подтверждается явно, ошибка не превращается в «пустой» результат.

## Документация

- Каждому модулю один файл `Documentation~/modules/<имя>.md` по шаблону `_TEMPLATE.md`.
- Каждая версия: запись в `CHANGELOG.md` и файл `Documentation~/versions/vX.Y.Z.md` по шаблону.
- Тексты короткие и однозначные, с таблицами API, примерами кода и явными запретами.

## Данные и сохранения

- Любое изменение формата сохранения: поднять номер схемы, добавить миграцию, записать в `compatibility.md`.
- Поля игры в сохранении добавляются через механизм расширения, а не правкой общей рамки.

## Что не коммитить

`Library`, `Temp`, `Build`, `Builds`, `Logs`, `UserSettings`, `*.csproj`, `*.sln`. См. `.gitignore`.
