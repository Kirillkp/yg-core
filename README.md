# yg-core

Общий Unity-пакет для игр на Яндекс Играх (WebGL) и тестовый стенд для его проверки.

- `Packages/com.kirillpolosov.yg-core/` — пакет.
- `Stand/` — проект-стенд: сцена с кнопками, на которой пакет проверяется в консоли Яндекса перед выпуском версии.
- `Docs/` — процесс выпуска, решения, план переноса из игры «Обби Потоп».

Для агентов начните с [AGENTS.md](AGENTS.md). Для человека: [README пакета](Packages/com.kirillpolosov.yg-core/README.md).

## Статус

Версия `0.1.0` выпущена: код модулей перенесён из «Обби Потоп», пакет собран в Unity и проверен на стенде в консоли Яндекса (реклама, вход, лидерборд, покупки, сохранение, язык, пауза). Запись версии: [versions/v0.1.0.md](Packages/com.kirillpolosov.yg-core/Documentation~/versions/v0.1.0.md). «Обби Потоп» пока на своём коде, переключение на пакет выполняется отдельным решением владельца. План и статус: [Docs/MIGRATION_FROM_OBBY.md](Docs/MIGRATION_FROM_OBBY.md).
