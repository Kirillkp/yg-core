# yg-core

Общий Unity-пакет для игр на Яндекс Играх (WebGL) и тестовый стенд для его проверки.

- `Packages/com.kirillpolosov.yg-core/` — пакет.
- `Stand/` — проект-стенд: сцена с кнопками, на которой пакет проверяется в консоли Яндекса перед выпуском версии.
- `Docs/` — процесс выпуска, решения, план переноса из игры «Обби Потоп».

Для агентов начните с [AGENTS.md](AGENTS.md). Для человека: [README пакета](Packages/com.kirillpolosov.yg-core/README.md).
